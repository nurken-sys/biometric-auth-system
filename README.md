# Тұлғаның биометриялық мәліметтері негізінде аутентификация жүйесін әзірлеу

Жүйе пайдаланушыларды бет-әлпеті және дауысы арқылы тануға, сондай-ақ қауіпсіз авторизациялауға арналған.

## 🛠 Технологиялар стегі
Бағдарламалау тілі: Python 3.x
Фреймворк: Django
Мәліметтербазасы: SQLite/PostgreSQL
Қосымша технологиялар: Face-API (бет-әлпетті тану), VOSK (дауысты тану)

## 📋 Негізгі мүмкіндіктері
* [x] Пайдаланушыларды жүйеге тіркеу және авторизациялау.
* [x] Бет-әлпет арқылы биометриялық тану.
* [x] Дауыс арқылы тану.
* [x] Жүйедегі барлық әрекеттерді мәліметтербазасына (db.sqlite3) сақтау.
